# technology-transfer-cell

## About

Technology Transfer Cell is an intellectual property management system, with a FastAPI backend and a React/Vite frontend. The repository also includes PostgreSQL Docker Compose configuration, project documentation, and Bruno API request collections.

## Project structure

| Path | Description |
|---|---|
| `backend/` | FastAPI backend and Python project dependencies. |
| `fronend/` | React/Vite frontend application. |
| `docs/` | Project context, function, and planning documentation. |
| `bruno/` | Bruno API request collection and environment. |
| `docker-compose.yml` | Docker Compose configuration for PostgreSQL. |
